# Milestone Website

A professional multi-page event website built in 2024 for **Milestone 2024**, the inter-school cultural fest of **St. George’s College, Mussoorie**. The project serves as the main digital hub for the event, presenting the homepage, event information, rules, schedule, and previous edition highlights in a structured and user-friendly way.

Milestone is one of the largest school events in Uttarakhand, with participation from multiple schools and over 700 attendees. The website was designed to help participants and visitors quickly access event details, navigate between pages, and explore the different competitions through clickable thumbnails.

## Features

- Homepage and landing page experience.
- Hero slider with event visuals.
- Countdown timer for the event.
- General rules page.
- Event schedule page.
- Individual event pages with clickable thumbnails.
- Event-specific rules and contact information.
- Previous year milestone video section.
- Clean folder-based structure for maintainability.

## How to Run

1. Clone the repository.
2. Open `index.html` in your browser.
3. Browse through the homepage and navigate to the event, rules, and schedule pages.

## Notes

- `index.html` is the main entry point of the project.
- The `Pages/` folder contains the homepage content as well as all supporting pages.
- `Events Img/` stores the images used for clickable thumbnails on event pages.
- `img/` contains general assets such as logos and banner images.
- `CSS/` and `JavaScript/` contain the styling and interactivity for the website.
